# CASEFLOW v0.7 — Operator Experience & Convenience Layer

This release adds the product foundation for ten high-value usability features:

1. Universal permission-aware search.
2. Role-personalized **My Work** dashboard.
3. Central **Needs Attention** exception inbox.
4. Matter timeline derived from immutable/audited workflow events.
5. Contextual quick actions.
6. Interactive marketer/publisher hierarchy UX.
7. Admin-controlled permission templates.
8. Tokenized publisher/agent invitation onboarding.
9. User-owned and optionally shared saved views.
10. Permission-aware **Ask CASEFLOW** / next-best-action foundation.

## Security boundaries

Search, AI assistance, saved views, My Work, and exception queues must never broaden the signed-in principal's authorization scope. View As sessions must continue to resolve the impersonated permission set server-side. Read-only View As must block mutations at the API layer. Invitation tokens are stored only as hashes and expire. Production LLM execution remains disabled until an approved provider, data-classification policy, vendor agreement/BAA where applicable, and prompt/response retention policy are configured.

## AI strategy

The included assistant API is deterministic scaffolding. It records authorized scope and returns workflow-derived next actions without transmitting claimant content to an external model. A production LLM adapter can later be added behind the provider registry and compliance gate.
