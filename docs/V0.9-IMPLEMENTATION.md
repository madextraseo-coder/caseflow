# CASEFLOW v0.9 — Communications, QC, Routing & Notifications

This release adds the third operator-convenience wave:

1. Unified communication inbox foundation using the existing communication message ledger.
2. Approved/versioned SMS, email, and internal-note templates.
3. Follow-up sequences with timed steps, enrollment, pause/resume/stop states, and suppression-aware stop policy.
4. Side-by-side document QC presentation in the browser demo.
5. Intelligent missing-document request event generation based on requested vs approved/released categories.
6. Law-firm capacity snapshots and capacity-board API.
7. Routing priority policies supporting priority, weighted, or round-robin distribution.
8. Mobile-first firm-review surface in the browser demo.
9. Notification-event ledger and user notification preferences.
10. Configurable daily digest time/channel foundation.

## Production gates

The browser demo remains fake/local-only. Real communication delivery, scheduled sequence execution, push/SMS notifications, mobile law-firm authentication, and live capacity calculation require production workers/providers, webhook verification, rate limiting, permission review, and approved data-handling configuration.
