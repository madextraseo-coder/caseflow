# CASEFLOW v1.1 API map

- `POST /api/v1/matters/:id/secure-send` — create an expiring, auditable secure document package for SMS/email/both/smart delivery.
- `GET /api/v1/agency/control-tower` — prioritized operational findings + latest command brief.
- `GET /api/v1/agency/morning-brief` — executive morning brief.
- `GET /api/v1/agency/war-room` — live operational telemetry.
- `GET /api/v1/matters/:id/journey` — chronological lead journey replay from audit events.
- `GET /api/v1/agency/revenue-intelligence` — publisher/campaign funnel snapshots.
- `GET /api/v1/agency/anomalies` — publisher anomaly feed foundation.
- `GET /api/v1/agency/priority-scores` — operational priority scores (not legal-merit/value predictions).
- `POST /api/v1/agency/routing-simulations` — dry-run routing simulations against historical data.
- `GET /api/v1/agency/geo-intelligence` — geographic case/qualification aggregation.
- `GET|POST /api/v1/agency/automation-rules` — allowlisted no-code automation rule definitions; new rules default to dry-run + approval required.
- `POST /api/v1/agency/copilot/actions` — governed Copilot action proposal; consequential actions require confirmation and are stored as proposals rather than executed directly.

Production completion still requires runtime schema verification, RLS/tenant tests, secure portal UI for share tokens/OTP, worker integration for SMART fallback, provider webhook verification, full routing simulation logic, anomaly baselines, geographic visualization, and approved external-AI provider policy before model execution.
